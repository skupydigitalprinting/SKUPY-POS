# PDF Unicode Font

Noto Sans SC, licensed under SIL Open Font License 1.1 (see OFL-NotoSansSC.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

NotoSansSC-Regular.ttf is the upstream variable TTF instantiated at weight 400
using fontTools varLib.instancer. It is fetched from the app's own assets only
when a PDF contains characters outside the standard Latin font range. jsPDF
embeds a subset of used glyphs in the generated PDF.
